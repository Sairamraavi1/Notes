We can create one common schema for the team and provide all five individual users access to the objects within that schema through object grants or preferably a common role. However, Oracle doesn’t provide a simple schema-level privilege that gives those users unrestricted create/write access only within that specific schema. If the requirement includes creating new tables, procedures, or other objects inside the common schema, we need to evaluate the privilege model separately because CREATE ANY privileges would be broader than just this schema. If they only need DML access to existing objects, the role-based approach is straightforward
